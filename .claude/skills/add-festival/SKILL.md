# 祭りを追加する

引数：祭りの名前（複数ならカンマ区切り）、または祭りのページのURL。
作業の前に CLAUDE.md の「データのルール」「行きやすさの基準」「人出」を読むこと。

## 手順

1. **重複を確認する**
   festivals.csv に同じ祭りがないか、名前の表記ゆれも含めて確認する。あれば追加せず、その旨を伝える。

2. **調べる**
   ウェブで次を確認する。公式サイト、または自治体・観光協会のページを優先する。
   - 正式名称、都道府県、市町村
   - メイン会場の緯度経度（小数点以下4桁以上）
   - 例年の開催ルール（「毎年8月2日〜7日」「10月第3日曜とその前日」など）と、次回の開催日
   - 公式URL、日程の出典URL
   - 見どころ、観覧・参加のコツ、豆知識
   - 人出（主催者・報道の発表値）。何年の何日間の数字かも確認する
   - 会場に最も近い高速道路IC（路線名・IC名、会場までの距離か所要時間）
   URLを渡された場合は、まずそのページを読み、足りない情報を追加で調べる。

3. **festivals.csv に1行追加する**
   id は今ある最大の id + 1。checked_on は今日の日付。確認できない項目は空欄にして、notes に「要確認」と書く。

4. **festival_details.json に同じ id で追加する**
   CLAUDE.md の形に合わせる。行きやすさは、つつじヶ丘から出かける前提で基準表に沿って付ける。
   lead・tips・trivia は、調べて確認できた内容だけで書く。

5. **地図を作り直す**
   `python build_map.py` を実行する。エラーが出たら内容に従って直し、成功するまで繰り返す。

6. **報告する**
   追加した祭りごとに、次を短く伝える。
   - 次回の開催日と行きやすさ（ふらっと／計画して／本気の遠征）
   - 「要確認」にした項目と、その理由
   - 人出の数字と出典（見つからなければ、推定にしたこと）
   最後に、ブラウザで matsuri-map.html を開けば確認できることを伝える。
